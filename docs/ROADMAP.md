# Product Roadmap

## Vision

Build the best discipleship platform for ministries by helping believers consistently engage with God's Word, prayer, learning, and community.

---

# Guiding Principles

* Ship value early.
* Prioritize user experience over feature count.
* Every release must improve discipleship.
* Never sacrifice security for speed.
* Measure outcomes, not outputs.

---

# Success Metrics

* Daily active disciples
* Bible reading consistency
* Prayer consistency
* Course completion
* Event attendance
* Community engagement
* Mentor participation

Success is measured by spiritual impact, not screen time.

---

# Out of Scope

Until MVP is complete, avoid:

* Donations
* Marketplace
* Chat system
* Live streaming
* Complex AI
* Public APIs
* Multi-tenancy

Focus on doing a few things exceptionally well.

---

# Product Principle

> **Finish the disciple journey before expanding the feature list.**
